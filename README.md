# Ucersoft Corporate Website

Next.js tabanli Ucersoft kurumsal web sitesi ve XStudio urun anlatimi.

## Kurulum

```bash
npm install
npm run dev
```

Yerel gelistirme sunucusu varsayilan olarak `http://localhost:3000` adresinde acilir.

## Komutlar

```bash
npm run dev
npm run build
npm run lint
```

## Proje Yapisi

- `app/`: sayfalar, layout ve global stiller
- `components/`: tekrar kullanilan React bilesenleri
- `public/`: marka gorselleri ve statik varliklar
- `scripts/`: build sonrasi yardimci scriptler
